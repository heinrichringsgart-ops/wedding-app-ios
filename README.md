# Wedding Planning App - iOS

En komprehensiv bryllupsplanlægnings-app bygget med SwiftUI og Firebase.

## Features

- 👥 **Gæstelist** - Administrer alle dine bryllupsgæster
- ✅ **RSVP Tracking** - Følg hvem der kommer
- 💰 **Budget Tracker** - Hold øje med udgifter
- 📅 **Timeline** - Planlægningskalender
- 📸 **Fotoalbum** - Del og gem bryllupsfoto
- 💬 **Chat** - Kommuniker med gæster
- 🎯 **Seating Arrangement** - Planlæg bordplaceringer

## Teknologi Stack

- **SwiftUI** - User Interface
- **Firebase** - Backend & Database
- **MVVM** - Architecture Pattern

## Kom i gang

1. Clone projektet
2. Åbn `WeddingApp.xcodeproj` i Xcode
3. Konfigurer Firebase
4. Build og run på simulator eller enhed

## Struktur

```
WeddingApp/
├── Models/           # Data models
├── Views/            # SwiftUI views
├── ViewModels/       # MVVM ViewModels
├── Services/         # Firebase & API services
└── Resources/        # Assets & colors
```

## Læringsmål

Dette projekt er designet til at lære:
- SwiftUI fundamentals
- MVVM architecture
- Firebase integration
- Async/await
- State management
